# technicalrecruiters.biz

Static site for Technical Recruiters LLC, hosted free on GitHub Pages.

- `index.html` is the whole site (HTML, CSS, JS in one file)
- `CNAME` maps the site to technicalrecruiters.biz
- Contact form posts to FormSubmit, which emails sam@technicalrecruiters.biz

Any commit to `main` goes live in about a minute.
